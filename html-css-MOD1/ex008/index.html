Texo marcado

Texto grande e pequeno

Estammos criando um texto grande e um texto pequeno

Texto deletado

Podemos marcar um texto como excluido para indicar que ele deve ser lido, mas não considerado, com DEL

Texto inserido

Podemos marcar um texto como incluido, para dar uma ênfase e indicar que ele foi adicionado depois, com INS (Semantico)

Existe também o sublinhado, com a tag U (Não semantica)

Texto sobrescrito

Para inserrir do tipo: x^20+3. Então, com a tag SUP: x20+3

Texto subescrito

Para inserir coisas do tipo: H2O. Então com a tag SUB: H2O
